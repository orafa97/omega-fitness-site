# Ômega Fitness

Landing page estática da Academia Ômega Fitness em Piedade de Caratinga, MG.

## Publicação

O site é HTML puro. `index.html` é a página inicial e `assets/` contém as fotos usadas. Na Vercel, importe este repositório como projeto com **Framework Preset: Other** e **Output Directory** vazio. Não há comando de build nem variáveis de ambiente.
